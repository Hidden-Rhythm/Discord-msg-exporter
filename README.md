## ✦ What is Discord Message Exporter?

**Discord Message Exporter** is a project designed to make Discord conversation history easier to preserve and work with outside the platform.

The goal is to provide a straightforward way to export accessible messages into organized, readable records, making them easier to archive, review, and manage.

This repository is currently in its initial setup stage. Specific functionality, supported export formats, and installation instructions will be documented as the implementation develops.

## 🔐 Privacy & Responsible Use

Conversation exports can contain personal messages, usernames, attachments, and other sensitive information.

Please keep the following in mind:

- Export only conversations and data you are authorized to access and preserve.
- Respect the privacy of other participants.
- Keep private exports out of public repositories.
- Never commit authentication tokens, session cookies, or credentials.
- Follow Discord's Terms of Service and applicable laws.

**Privacy matters:** Treat exported conversation archives as potentially sensitive, regardless of the export method.
